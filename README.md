# Automated-Knowledge-Base-KB-Article-Generator
Support engineers resolve dozens of tickets a week, but nobody has time to turn those messy comment threads into clean documentation. This Java utility takes raw ticket resolution notes, scrubs customer PII (emails/phone numbers) using regex first as a safety guardrail, and calls the OpenAI API to generate a standardized Markdown KB article.
To eliminate documentation bottlenecks after resolving complex incidents, I built a Java utility that automatically converts raw engineer troubleshooting notes into standardized Knowledge Base articles. Using Java's HttpClient and the OpenAI API, the tool scrubs customer PII via local regex guardrails before prompting the model to structure symptoms, root causes, and step-by-step resolutions into clean Markdown. This project taught me how to combine deterministic local preprocessing with LLM formatting to automate tedious team workflows without exposing sensitive user data.
